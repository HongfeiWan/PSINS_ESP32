离线窗外测试（2026-10-29）

本次用户同意固定朝向，准备使用保存的 manual 0°。摆放要求：
元件面朝上（ESP32 金属罩和芯片朝天），Type-C 所在的一边朝南，
GNSS 天线座所在的一边朝真北，即芯片 +Y 朝北、+X 朝东、+Z 朝天。
保持此朝向直到首次有效定位和组合导航初始化；本次建议全程固定，不拿着转动。
如用手机罗盘找北，请读取真北，并先远离天线磁铁、充电宝和金属件读方向。
近似对北用于功能验证，不能当成导航精度标定。

1. 先保持断电，接好天线和 TF 卡。拿到窗外或室外无遮挡处，先摆好上述朝向。
2. 摆好后再接移动电源供电；不要按住 BOOT 上电。上电后保持固定静止约 15 秒，以红灯慢闪为记录开始的准确信号。连续静止校准本身需约 5 秒。
   没有 Wi-Fi 或电脑也会保存 IMU、原始 NMEA 搜星信息、有效定位、PPS 和导航结果。
3. 天线接收面朝天；磁吸外壳款的塑料顶面朝上、磁铁底面向下。建议持续静置 10 分钟。不要先开机后一路转动搬运，以免途中已经初始化。
   板子也保持上述朝向，避免天线电缆拉扯接头；窗玻璃、遮挡和环境会影响接收。
4. 结束时在正常运行状态长按 BOOT 两秒，再松开；等待红灯常亮。
   常亮只在卡已正常结束记录、缓存排空且无写卡错误时出现，随后才能断电取卡。
   快闪可能是启动、正在保存、缺卡或错误；不能把快闪当成已经保存。
5. 回来最好保持同一移动电源供电，恢复 Wi-Fi 后让我取回这段记录。
   也可以常亮后断电，取出 TF 卡放读卡器；把整个 INSmini 文件夹复制到电脑后分析。
   中间重新上电会产生新的启动号，不能只取返程后的“当前段”。
   64 MiB 自动分段不等于一次试验结束，相关全部段都要保留。

分析工具：
  python tools/analyze_insmini_field.py <单段或INSmini文件夹> --output <电脑上的新报告目录>
工具分别核对：看见过卫星/载噪比、有效定位、PPS 与软件 UTC 锁定、
PSINS 实际导航记录、CRC/漏采/超量程/是否正常结束。不会只凭“ANTENNA OK”判定接收成功。
未正常结束的完整 CRC 前缀可用于诊断，但不会被冒充完整连续导航数据。
SIM 测试段默认排除；不会自动修补、删除或改写 TF 卡源数据。

保存离线初始方向的 API（仅设置流程使用）：
先停止记录并等待完全关闭，再 POST /api/navigation?mode=manual&heading=0&persist=1。
清除用 POST /api/navigation?mode=clear&persist=1，同样须先停止记录。
普通未加 persist 的设置仍仅影响当前启动；所有设置都要求真实摆放条件成立。
