# 验证状态（2026-10-29）

当前组合是 R2B 硬件 + 3.0.4 外场试用固件；5 片中只验证过 1 片，未把一片结果推广到其他四片。

## 已完成

- USB 正反插、下载，3.3 V 检查；LSM6DS3TR-C WHO_AM_I、自检、静止校准及网页姿态跟随。
- 3.0.4 的 12 轮文件启停/读回、35 秒 Wi-Fi 关闭期间记录、REAL/SIM 分离、严格 CRC/序号/时间间隔导入。
- 模拟 GNSS/PPS 轨迹含延迟、断流、错误校验、定位突跳、时刻跳变；PSINS 原数学接口与 GNU Octave 导入通过。Windows 未安装 MATLAB，未声称已做 MATLAB 实机验收。
- 后续用户实际断电重插，新启动原因 power_on，重新联网并自动记录，manual 0° 保留。用户反馈常亮→断电→慢闪；此前已用 API 停录，因此从正在记录状态经实体 BOOT 停录的完整实测仍待单独确认。
- 真实 GNSS 曾出现有效定位、PPS 和软件 UTC 锁定；本次真实记录中 PSINS 接受过 7 次 GNSS 融合。之后出现失锁/状态过期，不能称作稳定导航或精度合格。
- 格式化前最新 REAL 段：314915 个 IMU 样本、2915.892472 秒，逐记录 CRC/源标记通过，IMU 间断/硬件标记/存储丢弃为 0，正常结束；原始轨迹和无线配置不公开上传，已保留在私人归档。
- FAT32 快速格式化、空根和 4 KiB 写读校验通过；恢复相同 3.0.4 后，926 个 IMU 样本的新段、CRC 与结束标记通过，旧段目录已清除。此项不是整卡坏块或满卡测试。

## 已知失败与尚未验证

- 首个未发布 3.0.4 候选曾复现 SD 操作阻塞引发看门狗复位；已用项目本地 SD 驱动块边界让出 CPU 修复，没有关闭看门狗。
- 64 KiB 队列不是无限缓存。刻意将新文件启动积压与额外 5 秒停顿叠加，曾丢弃 259 条；该失败保留，未用后续通过的正常启停测试覆盖它。
- 没有自动删旧记录、循环覆盖或剩余容量提前预警。满卡主要在打开/写入失败时报告，尾段可能不完整；真实满卡边界未灌满测试。
- 无磁力计，人工 0° 不是测得的北向；未知初始方向不能冒充已知方向。低成本 MEMS 失去 GNSS 后会漂移。
- 实际 PPS 历元相位/微秒级同步精度、导航精度、室外动态轨迹、温漂/六位置/杆臂标定、Wi-Fi/GNSS 共存、长时间分段和突然断电可靠性尚未完成。
- openEMS 仅核对 1.55–1.62 GHz GNSS PCB 互连。完整两端口名义工况最小回波损耗约 14.680 dB、最大插损约 0.198 dB；原先全带 15 dB 目标未全部通过。
