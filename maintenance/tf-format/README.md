# 一次性 TF 格式化维护程序

此目录是独立的维护应用，正常导航请用 `../../firmware/insmini-nav`。源码对应 2026-10-29 在一片 R2B 上执行过的格式化工具；原导航应用已恢复。

构建：`pio run -d maintenance/tf-format -e formatter`。

程序固定核对 MAC `80:45:6b:44:07:68`、TF 卡检测、唯一 SPI SD 卷和卡容量。上电不自动格式化；串口 115200 发送 `PREVIEW`，查看 `FORMAT_PREVIEW`。只有将本次启动返回的 `confirm_command` 原样发送，才执行一次 FAT32 快速格式化。命令含当前卡容量和随机值，重复或错误命令拒绝。格式化会清空该卡的文件，应先自行备份。

工具只使用 SD/HSPI（CS35、MOSI36、SCK37、MISO38、DETECT47），不挂载 ESP32 内部 Flash 文件系统。独立 NVS 初始化绕过防止 Arduino 异常恢复分支擦 NVS；它无 Wi-Fi 或 NVS 客户端，不用于正常应用。

实际检查：约 32 GB 卡、FAT32、32 KiB 簇、重挂载、空根目录、4096 字节内容/CRC/EOF 校验及删除测试文件均通过；CRC 为 `047b89e9`。随后恢复原 3.0.4，确认 Wi-Fi、manual 0°、自主记录、下载 CRC 和正常停录。没有做整卡坏块扫描，也不代表满卡/突然掉电验收。

这是为单片已验证板保留的维护源码；其他硬件、不同 SD 接线或 MAC 不直接兼容。刷写前先确认身份/分区并备好原导航镜像，仅应用区更新；任何失败先恢复导航固件，不自动重复格式化。
