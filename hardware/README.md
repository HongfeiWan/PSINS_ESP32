# INSmini 硬件

| 版本 | 板框 | 定位 |
|---|---|---|
| [R1](R1/) | 35×43 mm | 原始历史版，后续发现 USB 等问题，已由 R2/R2B 替代 |
| [R2](R2/) | 39×43 mm | USB 布线修订版，后续又完成 R2B 射频外围修订 |
| [R2B](R2B/) | 39×43 mm | 当前实物版本；5 片全代贴，1 片做过本文列明的测试 |

当前硬件：ESP32-S3-WROOM-1-N8（8 MB Flash、无 PSRAM）、LSM6DS3TR-C 六轴 IMU、ATGM336H-5N31 GNSS、TF 卡、USB-C 与 J4 扩展接口。四层 1.6 mm，外层 1 oz。

R2B 下单使用同一目录的 Gerber ZIP、BOM、CPL，禁止跨版本混用。7628 叠层 L1–L2 介质 0.20 mm、Dk 4.6；叠层变化须重新核对射频/USB。原生工程内部历史名字可能仍含 R1，以本目录版本、PCB 丝印和校验值区分。

R2B 已运行 openEMS 的 GNSS PCB 互连仿真；原先全带 15 dB 回波损耗目标仍有未通过点，原报告保留该结论。仿真不包含整套天线、模组内部或 Wi-Fi 共存。报告、Touchstone、曲线、制造一致性与电气检查均在 R2B 目录。

公开原生工程只清空软件账户密码字段，其他设计数据逐表核对一致；制造 Gerber/BOM/CPL 字节不变。原始本地交付件与原校验表保留，不把重新整理的公开目录冒充原始交付 ZIP。
